СВОИ ШТУКИ — личная витрина приложений

Как открыть
-----------
Откройте index.html в браузере. Для просмотра приложений сайт не требует
сервера или установки зависимостей. В каталоге можно искать и сортировать
проекты, фильтровать их по категориям и сохранять избранное в браузере.
Сайт по умолчанию открывается в тёмной теме; переключатель запоминает выбор.
Страница адаптируется под телефон и компьютер. Кнопка «Подробнее» открывает
описание проекта; ссылка на загрузку находится только в карточке подробностей.
В правом нижнем углу расположена подпись byQwinstar.

Скриншот WorkTimer находится в images/worktimer-screenshot.png.

Как опубликовать на GitHub Pages
--------------------------------
Для сайта подготовлен workflow .github/workflows/pages.yml. Важно: создай
отдельный репозиторий только для содержимого папки «Мои приложения». НЕ
загружай корневую папку проекта TelegramBot или весь проект на GitHub: там
находятся другие исходники и конфигурация, которые не относятся к сайту.

1. Создай на GitHub новый отдельный репозиторий, например my-apps-site.
   Для бесплатной публикации GitHub Pages через Actions репозиторий должен
   быть публичным.
2. Открой PowerShell и перейди именно в папку сайта:

     cd "C:\путь\к\проекту\TelegramBot\Мои приложения"

3. Установи Git, если команда git пока не работает. Затем выполни команды,
   подставив адрес своего репозитория:

     git init -b main
     git add index.html styles.css apps.js README.txt images downloads .github
     git commit -m "Create app portfolio website"
     git remote add origin https://github.com/ТВОЙ-АККАУНТ/my-apps-site.git
     git push -u origin main

   Если Git просит имя и email для коммита, укажи их командами
   git config --global user.name "Твоё имя" и
   git config --global user.email "ТВОЙ-EMAIL".
4. В GitHub открой созданный репозиторий, затем Settings → Pages. В разделе
   Build and deployment выбери Source: GitHub Actions.
5. Открой вкладку Actions и дождись успешного запуска «Publish website to
   GitHub Pages». Адрес сайта появится в Settings → Pages и в результате
   workflow.
6. Для следующих изменений из папки сайта запускай git add, git commit и
   git push. Публикация обновится автоматически.

Делай git init внутри папки «Мои приложения», а не в родительской папке
TelegramBot. Тогда в отдельный репозиторий попадут только файлы сайта.

Формы на GitHub Pages
---------------------
GitHub Pages размещает статические файлы и сам не принимает заявки. Чтобы
форма работала, создай форму на Formspree и укажи её endpoint в начале файла
apps.js вместо пустого значения:

  const formEndpoint = "https://formspree.io/f/ТВОЙ_ID";

Подтверди свой email в Formspree и опубликуй apps.js снова. Пока endpoint не
настроен, форма честно сообщит, что заявка не отправлена. После подключения
заявки отправляются в сервис Formspree; в его настройках можно выбрать почту
для уведомлений. Форма собирает тип заявки, имя или ник, выбранный способ
связи (Telegram, Discord или email), контакт и описание проекта. Не указывай
секретные ключи в файлах сайта.

Как добавить приложение
-----------------------
1. Положи установщик или архив в папку downloads.
2. Открой apps.js и добавь объект в массив apps. Пример:

  {
    name: "Моё приложение",
    category: "Утилиты",
    description: "Коротко расскажите, что делает приложение.",
    icon: "✳",
    iconBackground: "#e5edda",
    iconColor: "#6e8d38",
    platform: "Windows",
    version: "Версия 1.0",
    details: "Подробное описание приложения.",
    features: ["Первая возможность", "Вторая возможность"],
    download: "downloads/MyApp.exe",
    downloadInfo: "MyApp.exe · 12 МБ · приложение для Windows",
    tag: "Опубликовано",
  },

3. Укажи путь к файлу относительно этой папки в поле download.
   Для проекта без готовой загрузки удалите поле download —
   карточка автоматически покажет «Скоро появится».
4. Сохрани apps.js и обнови страницу.

Поля details и features используются в карточке подробностей. Поле
downloadInfo поясняет тип и размер файла рядом со ссылкой загрузки.
У приложений без файла для скачивания будет показан статус проекта.

Сайт подготовлен для GitHub Pages. Форма начнёт отправлять заявки после
подключения Formspree endpoint. Если установщик большой, его можно хранить
отдельно и указать в download прямую ссылку на него.
